# GitHub Release Audit

Audit date: 2026-08-05
Original branch: `feature/goai-education-agent`
Release branch: `release/goai-submission`
Starting commit: `73fc684196dc63cca5732f71de167c6ab9942259`
Remote status: no Git remote configured at audit time

## Scope

This audit covers tracked and untracked files, local runtime artifacts, public
documentation, provider exposure, reproducible evaluation outputs, submission
materials, filename encoding, repository structure, and security-sensitive
content. No business architecture or scoring behavior is changed by the release
cleanup.

## KEEP

- Application code under `app/`, except the unused provider listed under
  `REMOVE_FROM_REPOSITORY`.
- `case_templates/` with 20 structured, synthetic educational YAML cases.
- `tests/` and all active test modules.
- `experiments/` runners, authored transcripts, and small CSV/JSON/Markdown
  benchmark outputs.
- `evaluation/` runner, metrics, report, and reproducible scenario outputs.
- `assets/demo_traces/` and the eight documented Streamlit prototype screenshots.
- `docs/`, including `docs/中文面试准备_SimuPatient.md`; the filename is valid
  UTF-8 and the content is unique rather than a duplicate encoded as `#Uxxxx`.
- `submission/`, including the project introduction, prototype guide, demo
  materials, PPTX, and PDF deck.
- Existing phase reports plus the release reports created by this cleanup.
- `streamlit_app.py`, `README.md`, `TECHNICAL_REPORT.md`, `requirements.txt`,
  `pyproject.toml`, `.env.example`, `.streamlit/secrets.toml.example`,
  `.gitignore`, and the MIT `LICENSE`.

## REMOVE_FROM_REPOSITORY

- `.pytest_cache/`.
- Every `__pycache__/` directory and compiled Python file.
- `simupatient.db`.
- `evaluation/results/ui_evidence_phase6.db`.
- `app/providers/openai_provider.py`: the module is not connected to the
  provider factory, its optional dependency is absent, it has no tests, and it
  references settings fields that do not exist. Publicly supported providers
  remain Mock, Gemini, and Ollama.

The runtime artifacts were ignored and not tracked. Their removal is a local
workspace cleanup. The unused provider was tracked and is removed from the
public repository.

## KEEP_LOCALLY_BUT_IGNORE

- `.env` and environment-specific variants, except `.env.example`.
- `.streamlit/secrets.toml`.
- `.venv/`, `venv/`, and `env/`.
- `.vscode/` and `.idea/`.
- Local SQLite databases, logs, coverage output, build output, and temporary
  files generated after this cleanup.

No private environment file, Streamlit secret, virtual environment, or IDE
configuration was present as a tracked file at audit time.

## REVIEW_REQUIRED

- Three pre-existing worktree edits in `docs/goai_gap_analysis.md`,
  `docs/goai_upgrade_plan.md`, and `reports/phase_0_report.md`. They record the
  latest local re-audit and are retained as part of the release documentation.
- Eight screenshots. Representative learner, safety-block, and instructor
  views were visually inspected and match the documented local Streamlit
  prototype. They contain synthetic demo identifiers rather than patient data.
- Submission PPTX and PDF. They are retained because they are competition
  materials and are subject to render/open checks during validation.
- Reproducible evaluation CSV/JSON/Markdown files. They are small, generated by
  checked-in scripts, and retained even when results expose known calibration
  limitations.
- Public naming. Version-suffixed branding was found in the app title and
  documents and is removed during this release cleanup.

## Repository Structure

The repository root directly contains `app/`, `case_templates/`,
`streamlit_app.py`, and `README.md`. No nested `Simu_Patient/Simu_Patient/`
checkout or duplicate project root was found.

## Initial Security Findings

- No tracked database, cache, compiled Python file, `.env`, or
  `.streamlit/secrets.toml` was found.
- Secret-pattern matches were configuration names and explicit placeholders in
  example files and documentation; no credential value was identified.
- No tracked personal absolute path was found.
- The repository uses structured synthetic educational cases; no real-patient
  dataset was identified.
- Public text repeatedly states that internal benchmarks are not clinical
  validation. The release scan will preserve that boundary.

## Audit Decision

Proceed with release cleanup on `release/goai-submission`. Preserve business
code, tests, evaluation evidence, screenshots, and submission materials; remove
only confirmed local artifacts and the disconnected provider module; then run
the complete validation suite before committing.
