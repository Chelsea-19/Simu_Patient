# SimuPatient 作品简介

SimuPatient 面向医学生、OSCE 学习者与医学教师，解决标准化患者训练成本高、机会少，以及普通 AI 对话缺少稳定病例状态、过程诊断和针对性复训的问题。学习者选择目标后，与结构化虚拟患者多轮问诊，调用生命体征、查体、ECG 和检验工具，提交鉴别诊断与处置；Safety Supervisor 阻断危险组合，Assessment and Coaching Agent 基于确定性清单、Action Trace 与受限语言反馈生成九维学情诊断，Learning Planner 据弱项创建 Focused Retry 并比较两轮表现。病例事实和检查结果来自教育用途 YAML 合成模板，规则引擎控制解锁、安全和基础评分，LLM 仅负责受约束的语言理解与表达，SQLite 保存训练轨迹。学生端与教师隐藏状态隔离，项目不使用真实患者数据，不用于诊疗或高风险正式考试。当前已完成无 API 闭环、教师视图、病例验证器、15 条评测轨迹及部署文档；MIT 开源的 YAML Schema、工具接口、安全规则和 MockProvider 可供教学复用。
